# 教材用Webコーステンプレート

手順を1つずつ「できた」で進めていく、ロードマップ型の教材サイトを作るためのテンプレートです。章・手順・用語集・振り返りチェックリストを1つのファイルに書くだけで、進捗の保存、用語のポップアップ、目次などが付いた教材サイトができあがります。

## 主な機能

- 章ごとの手順を開閉しながら進め、「できた」で完了を記録（進捗はブラウザに保存）
- トップのロードマップと「次にやること」の案内
- 本文中の用語をタップすると意味が出る用語集
- 振り返りチェックリスト
- スマートフォン対応、ビルド後は静的ファイルだけで公開可能

## 教材の作り方

**教材の中身はすべて `course/course.ts` に書き**、画面の仕組み（`src/`）やデザイン（`src/styles/`）は触らずに新しい教材を作れます。

### 手順

1. このリポジトリをコピーし、`npm install` を実行します。
2. `course/course.ts` を開き、【】で囲んだ仮の文字を、作る教材の内容に書き換えます。
3. `npm run dev` で画面を確認しながら編集します。`course.ts` を保存すると自動で再読み込みされます。
4. `npm run build` で `dist/` に公開用のファイルができます。

> **必ず `meta.storageKey` を教材ごとに別の値にしてください。** 同じドメインに同じキーの教材を置くと、進捗が混ざります。

### course.ts の構成

| 項目 | 内容 |
|---|---|
| `meta` | タイトル、トップの大見出し（`heroLines`、`*語*` で強調色）、リード文、発行元、進捗の保存キーなど |
| `theme` | 強調色（`accent` など）。省略すると緑 |
| `intro` | 「はじめに」ページの本文、準備するもの、注意枠 |
| `legs` | ロードマップの区切り（導入・準備・開発…）。省略すると「導入／本編／確認」の3つ |
| `chapters` | 章の一覧。章ごとに `title`、`services`、`summary`、`steps`（手順）、`points`、`warn` を書く |
| `glossary` | 用語集。本文中の最初の出現が自動でタップできる語になる（`autoLink: false` で無効） |
| `checklist` | 振り返りチェックリストの項目と、関連する章 |
| `references` | 参考リンク |
| `ui` | 画面の決まり文句の上書き（英語の教材にするときなど）。一覧は `template/ui.ts` |

章の数・手順の数・「全6章・45手順」などの表示、目次、前へ／次へのリンクは自動で作られます。

### 本文の書き方

- `title` などの名前は文字のまま表示されます。`body`・`points`・`lead` などの本文にはHTML（`<strong>`、`<code>` など）を使えます。
- 文章だけの本文は自動で段落になります。手順の `body` を配列にすると、複数の段落やブロックを並べられます。
- `template/index.ts` から次の部品を読み込んで使えます。

| 部品 | 使い方 |
|---|---|
| `link(url, 表示名?)` | 新しいタブで開く外部リンク |
| `prompt(文章, 見出し?)` | コピーボタン付きのプロンプト例 |
| `copyCode(文字)` | コピーボタン付きの短いコード |
| `sub([...])` | 手順の中の小さな箇条書き |
| `points([...])` | 強調付きの箇条書き |

### 章の記入例

章を増やすときは、`chapters` の中に次のようなまとまりを足します（IDは `ch2`、`ch3` … と続けます）。

```ts
{
  id: 'ch2',
  title: 'アカウントを作る',
  navTitle: 'アカウント作成',          // 目次用の短い名前（省略可）
  services: ['サービスA'],
  summary: 'サービスAに登録します。',
  steps: [
    {
      title: 'サイトを開く',
      body: `ブラウザで ${link('https://example.com')} を開きます。`,
    },
    {
      title: 'AIに頼む',
      body: ['入力欄に次のように書きます。', prompt('〇〇を作ってください。')],
    },
  ],
  points: ['登録したメールアドレスは<strong>控えておきましょう</strong>。'],
  warn: { title: '注意', body: 'パスワードは他のサービスと使い回さないでください。' },
},
```

部品を使うときは、`course.ts` の先頭の読み込みに足します：`import { defineCourse, link, prompt } from '../template/index.ts';`

### 注意

- 進捗は「章ID-手順の番号」（例：`ch1-3`）で保存されます。公開後に章のIDを変えたり、手順を途中に追加・削除したりすると、受講者の進捗の記録がずれます。
- 章IDの書き間違い、手順のない章、存在しない章を指すチェック項目などは、`npm run dev` / `npm run build` の時点でエラーとして表示されます。

### フォルダの構成

```
course/course.ts     教材の中身（ここだけ編集する）
template/            course.ts からページを組み立てる仕組み（型、部品、Viteプラグイン）
src/                 ブラウザで動く処理（進捗、用語集、画面の切り替えなど）とデザイン
index.html           外枠。中身はビルド時に course.ts から差し込まれる
```
